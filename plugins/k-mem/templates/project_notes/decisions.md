# Architectural Decision Records

One file per decision under `decisions/` (`ADR-NNN-slug.md`). This file is the generated index over them; `kmem notes index` rewrites everything below the marker. Create the next decision with `kmem notes adr "Title"`.

Convention: every ADR heading carries a status tag (`[ACCEPTED]`, `[PROPOSED]`, `[SUPERSEDED]`), a `**Date**` line and a `**Status**` line. Cross-repo references carry the other repo's alias (`other ADR-NNN`); a bare `ADR-NNN` always means this repo.
